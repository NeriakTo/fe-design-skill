# 5 維度設計評審框架（Design Critique Guide）

> 靈感來源：alchaincyf/huashu-design 的等效能力描述。本文件為獨立撰寫，不含原始碼引用。

## 何時觸發

- 使用者請求「評審」「好不好看」「review」「打分」
- 主腦對產出有疑問，主動質檢
- fe-design Stage 6 品質檢核第二道（anti-slop 之後）

## 5 維度評分標準

### 1. 哲學一致性（Philosophy Alignment）— 權重 20%

| 分數 | 標準 |
|---|---|
| 9-10 | 完美體現選定設計方向的核心精神，每個細節都有哲學依據 |
| 7-8 | 整體方向正確，核心特徵到位，個別細節偏離 |
| 5-6 | 能看出意圖，但混入了其他風格元素 |
| 3-4 | 僅在表面模仿，未理解哲學內核 |
| 1-2 | 與選定哲學基本無關 |

**審查要點**：
- 是否使用了該設計方向的標誌性手法？
- 色彩、字體、佈局是否符合該體系？
- 有沒有「自相矛盾」的元素？

### 2. 視覺層級（Visual Hierarchy）— 權重 25%

| 分數 | 標準 |
|---|---|
| 9-10 | 視線自然沿設計者意圖流動，資訊獲取零摩擦 |
| 7-8 | 主次關係清晰，偶有 1-2 處層級模糊 |
| 5-6 | 能分出標題和正文，但中間層級混亂 |
| 3-4 | 所有元素視覺權重相近，無法辨識重點 |
| 1-2 | 完全混亂，找不到入口 |

**審查要點**：
- 使用者 3 秒內能否抓到核心訊息？
- 標題 → 副標 → 正文 → 輔助資訊的視覺梯度是否足夠？
- 留白是否服務於層級而非裝飾？

### 3. 細節執行（Craft Quality）— 權重 25%

| 分數 | 標準 |
|---|---|
| 9-10 | 排版精度達印刷級，間距完全一致，字體渲染完美 |
| 7-8 | 整體精緻，偶有 1-2 處微小不一致（2px 級） |
| 5-6 | 大致整齊但能看出「沒有對齊」的地方 |
| 3-4 | 間距混亂，元素大小不統一 |
| 1-2 | 明顯草率，像是沒有校對 |

**審查要點**：
- 同類元素間距是否一致？（padding / margin / gap）
- 文字是否有 orphan / widow？
- 圖片比例是否正確？
- 色值是否精確引用 design tokens（而非近似值）？

### 4. 功能性（Functionality）— 權重 20%

| 分數 | 標準 |
|---|---|
| 9-10 | 所有互動都可操作，accessibility 完備，響應式完美 |
| 7-8 | 核心功能正常，個別邊界情境未處理 |
| 5-6 | 主流程可走通但有可感知的 bug |
| 3-4 | 部分功能失效 |
| 1-2 | 基本不可用 |

**審查要點**：
- 所有連結 / 按鈕是否可點擊？
- Playwright 跑完有無 console error？
- 鍵盤導航是否可用？
- aria-label 是否正確？

### 5. 創新性（Innovation）— 權重 10%

| 分數 | 標準 |
|---|---|
| 9-10 | 在品味範圍內做到「值得截圖」的差異化表現 |
| 7-8 | 有 1-2 處令人驚喜的設計細節 |
| 5-6 | 中規中矩，符合預期但無驚喜 |
| 3-4 | 過於保守，像模板產出 |
| 1-2 | AI slop 典型特徵 |

**審查要點**：
- 有沒有「一處做到 120%」的簽名細節？
- 是否超越了「最大公約數」的通用設計？
- 在不犧牲功能性的前提下，是否有獨特的視覺語言？

## 輸出格式

```markdown
## 設計評審報告

### 總分：X.X / 10（加權平均）

### 雷達圖
<!-- 使用 scaffolds/radar_chart.mjs 產生 SVG -->

### Keep（做得好的）
1. ...
2. ...
3. ...

### Fix
- ⚠️ 致命：...
- ⚡ 重要：...
- 💡 優化：...

### Quick Wins（5 分鐘可做的前 3 件事）
1. ...
2. ...
3. ...
```

## 雷達圖使用

```js
import { RadarChart } from '~/.claude/skills/starter-components/scaffolds/radar_chart.mjs';

const html = RadarChart({
  dimensions: [
    { label: '哲學一致性', value: 8 },
    { label: '視覺層級', value: 7 },
    { label: '細節執行', value: 9 },
    { label: '功能性', value: 6 },
    { label: '創新性', value: 7 },
  ],
  title: '範例公司 全日方案 v3 評審',
  color: 'var(--color-accent, #0ea5e9)',
});
```

## 加權平均計算

```
總分 = (哲學 × 0.20) + (層級 × 0.25) + (細節 × 0.25) + (功能 × 0.20) + (創新 × 0.10)
```
