## 流派 1：資訊建築派（01-04）

視覺氣質：理性、數據驅動、克制
適合作為：安全/專業選擇
適用場景：企業提案、年報、數據 dashboard、consulting deck

### 01 Pentagram 資訊建築

**哲學內核**：資訊即結構。每個視覺元素都是資訊層級的映射，沒有裝飾。

**核心特徵**：
- 嚴格的模組化網格（12/16 column）
- 單色 + 一個 accent 色（通常是黑 + 紅/橙）
- Helvetica Neue / Neue Haas Grotesk 等中性無襯線體
- 大量留白作為資訊分隔

**氣質關鍵詞**：權威、專業、克制、系統化、永恆

**適用場景**：企業年報、品牌手冊、consulting deck、提案簡報

### 02 Stamen Design 地理資訊

**哲學內核**：地圖不是裝飾，是理解世界的透鏡。資料視覺化應該既精確又美麗。

**核心特徵**：
- 地理空間資料為核心視覺元素
- 柔和的自然色調（水藍、淺灰、暖土色）
- 資料密度高但層級清晰（透過透明度和色相分離）
- 互動式 tooltip 揭示細節

**氣質關鍵詞**：探索、精確、溫暖、知識、層次

**適用場景**：地理資料視覺化、環境報告、城市規劃、供應鏈地圖

### 03 Information Architects 排版系統

**哲學內核**：資訊架構先於視覺設計。先建立閱讀順序，再考慮美觀。

**核心特徵**：
- 極度重視 typography hierarchy（6+ 級字級梯度）
- 單一字體家族的不同字重承載所有層級
- 極簡色彩（黑/白 + 一個連結色）
- 大量行距、字距微調

**氣質關鍵詞**：清晰、可讀、秩序、學術、沈靜

**適用場景**：長文閱讀、技術文件、學術報告、editorial

### 04 Fathom 資料藝術

**哲學內核**：資料可以同時是精確的和詩意的。視覺化不只是工具，是一種表達。

**核心特徵**：
- 生成式資料視覺化（用演算法從資料生成形狀）
- 深色背景 + 明亮發光的資料點
- 有機的線條和形狀（非傳統長條/圓餅）
- 微動畫讓資料「呼吸」

**氣質關鍵詞**：詩意、精確、有機、發光、探索

**適用場景**：資料敘事、年度回顧、科學視覺化、動態 dashboard

## 流派 2：運動詩學派（05-08）

視覺氣質：動感、沈浸、技術美學
適合作為：大膽/前衛選擇
適用場景：產品發布、品牌宣傳、技術展演

### 05 Locomotive 滾動敘事

**哲學內核**：滾動是最自然的敘事介面。每次滾動都應該推進一個故事。

**核心特徵**：
- 全頁滾動觸發的動畫序列
- 視差效果（多層不同速度）
- 大字標題 + 沈浸式圖片
- 進度指示器（非傳統捲軸）

**氣質關鍵詞**：電影感、沈浸、節奏、流動、敘事

**適用場景**：品牌故事、產品 landing page、作品集、年度回顧

### 06 Active Theory 沈浸體驗

**哲學內核**：螢幕是一個可以伸手進去的空間。設計應該讓使用者忘記自己在用瀏覽器。

**核心特徵**：
- WebGL / Canvas 為主視覺載體
- 3D 空間感（景深、光影）
- 極少 UI chrome，全螢幕沈浸
- 滑鼠/觸控互動驅動視覺變化

**氣質關鍵詞**：未來、沈浸、科技、空間、探索

**適用場景**：品牌體驗站、產品發布會、科技展演

### 07 Field.io 生成粒子

**哲學內核**：美來自演算法和物理規則的湧現。每一幀都是獨一無二的。

**核心特徵**：
- 粒子系統 / 流場 / 引力模擬
- 深黑背景 + 細線 + 微粒子
- 即時互動（滑鼠影響力場）
- 有機但可控的運動模式

**氣質關鍵詞**：生成、有機、科技、詩意、獨一無二

**適用場景**：品牌 hero 動畫、技術產品展演、藝術裝置

### 08 Resn 互動敘事

**哲學內核**：每個互動都是一個小故事。使用者不是在「用」，是在「玩」。

**核心特徵**：
- 遊戲化的互動模式（拖拽、碰撞、物理引擎）
- 色彩鮮明、飽和度高
- 聲音回饋（點擊、拖拽、完成）
- 非線性敘事（使用者選擇路徑）

**氣質關鍵詞**：玩心、鮮明、互動、驚喜、非線性

**適用場景**：品牌推廣、教育互動、活動網站

## 流派 3：極簡主義派（09-12）

視覺氣質：秩序、留白、精緻
適合作為：安全/高端選擇
適用場景：高端品牌、設計系統、學術文件

### 09 Experimental Jetset 瑞士現代

**哲學內核**：設計是一種語言系統，不是自我表達。每個決定都有規則依據。

**核心特徵**：
- 嚴格的 Swiss Grid
- Helvetica / Akzidenz-Grotesk
- 黑白為主 + 原色系 accent（紅/藍/黃）
- 幾何構成（圓形、直線、矩形）

**氣質關鍵詞**：系統、規則、幾何、永恆、純粹

**適用場景**：設計系統文件、品牌規範、藝文展覽

### 10 Müller-Brockmann 網格系統

**哲學內核**：秩序即美。網格不是限制，是自由的骨架。

**核心特徵**：
- 數學精確的網格分割
- 強調比例和韻律（黃金比例、費波那契）
- 極少裝飾，讓結構本身成為美
- 大量正負空間對比

**氣質關鍵詞**：秩序、數學、比例、韻律、莊嚴

**適用場景**：資訊圖、數據報告、學術海報、consulting deck

### 11 Build 英式極簡

**哲學內核**：少即是多，但少的那些必須精緻到極致。

**核心特徵**：
- 大面積單色 + 精密的 typography
- Serif display + Sans body（英式傳統配對）
- 細節品味：小型大寫字母、數字型 oldstyle figures
- 建築感的佈局（列、柱、基線對齊）

**氣質關鍵詞**：精緻、英式、建築、細節、品味

**適用場景**：高端品牌、精品提案、建築事務所

## 流派 4：實驗先鋒派（13-16）

視覺氣質：先鋒、生成藝術、視覺衝擊
適合作為：大膽/創新選擇
適用場景：創新提案、技術展演、品牌差異化

### 12 Sagmeister & Walsh 實驗排版

**哲學內核**：美可以客觀衡量。排版可以是雕塑、可以是行為藝術、可以是一切。

**核心特徵**：
- 排版即圖像（文字變成視覺元素）
- 跨媒材表現（實體裝置 → 數位轉譯）
- 強烈的色彩對比
- 不按規則的佈局（故意破格但有控制）

**氣質關鍵詞**：實驗、大膽、跨界、情感、挑釁

**適用場景**：品牌重塑、創意提案、藝術展演

### 13 Zach Lieberman 生成藝術

**哲學內核**：程式碼是畫筆。每天畫一幅「sketch」，用演算法探索美的邊界。

**核心特徵**：
- 即時生成的有機形狀
- 極簡色盤（通常 2-3 色）
- 手繪 + 數位的混合質感
- 每次運行都不同的結果

**氣質關鍵詞**：手作、生成、探索、溫暖、獨特

**適用場景**：品牌 hero 圖、社群封面、限定活動

### 14 Raven Kwok 算法視覺

**哲學內核**：演算法是設計師。規則越簡單，湧現的複雜度越驚人。

**核心特徵**：
- 遞迴幾何（分形、voronoi、L-system）
- 高對比黑白 + 單色螢光 accent
- 精密到像素的對稱
- 從簡單規則生成複雜圖案

**氣質關鍵詞**：精密、對稱、算法、未來、冷峻

**適用場景**：技術產品封面、AI/ML 品牌、科學視覺化

### 15 Ash Thorp 科幻介面

**哲學內核**：介面是角色。UI 設計可以有自己的性格、聲音、和故事。

**核心特徵**：
- 深黑底 + 冷藍/青色 HUD
- 細線 + 微光 + 半透明面板
- 仿科幻電影 UI（Minority Report / Blade Runner 2049）
- 大量數據讀數和進度指示器

**氣質關鍵詞**：科幻、冷峻、高科技、沈浸、電影

**適用場景**：技術展演、VR/AR 介面概念、科技品牌

### 16 Territory Studio FUI

**哲學內核**：Fantasy UI 的存在是為了敘事，不是為了功能。每個螢幕都在說一個故事。

**核心特徵**：
- 影視級 UI 設計（為電影/遊戲設計的介面）
- 深色 + 高對比 accent（琥珀/青/紅）
- 動態數據流 + 即時更新效果
- 層次豐富的半透明面板

**氣質關鍵詞**：電影、敘事、層次、動態、奇觀

**適用場景**：品牌概念影片、技術願景展示

## 流派 5：東方哲學派（17-20）

視覺氣質：溫潤、詩意、思辨
適合作為：差異化/獨特選擇
適用場景：文化類、教育類、年報、東亞市場

### 17 Takram 日式設計工程

**哲學內核**：設計 + 工程 = 同一件事。兩者的交叉點才是最有趣的地方。

**核心特徵**：
- 精密但溫暖的網格
- 日式色彩（灰調暖色 + 一個冷 accent）
- 功能性與美感的無縫融合
- 細膩的 micro-interaction（hover 呼吸、scroll 吸附）

**氣質關鍵詞**：精密、溫暖、工藝、融合、細膩

**適用場景**：科技 × 人文的交叉專案、服務設計、設計系統

### 18 Kenya Hara 東方極簡

**哲學內核**：「空」不是「沒有」，是「全部的可能性」。留白是最強的設計元素。

**核心特徵**：
- 極度留白（60-70% 空白面積）
- 自然材質感（紙質紋理、墨跡邊緣）
- 超細字重的無襯線體
- 單一焦點（每頁只有一件事）

**氣質關鍵詞**：空、靜、自然、本質、可能性

**適用場景**：高端品牌、年報封面、文化展覽、冥想/健康 App

### 19 Irma Boom 書籍建築

**哲學內核**：書是建築，每一頁是一個空間。翻頁是一次空間穿越。

**核心特徵**：
- 非傳統的頁面比例和裁切
- 出血印刷 + 意外的折頁
- 材質混搭（光面/霧面/透明紙的交替）
- 圖像壓到版面邊緣

**氣質關鍵詞**：建築、空間、材質、實驗、敘事

**適用場景**：品牌書、年報、作品集（數位版可模擬翻頁和材質感）

### 20 Neo Shen 東方未來

**哲學內核**：東方美學 × 科技未來 = 新的視覺語言。水墨可以是粒子，書法可以是動態排版。

**核心特徵**：
- 水墨/書法 × 數位粒子的混合
- 深底 + 金/朱/墨色系
- 動態書法（筆劃生成動畫）
- 東方構圖（不對稱平衡、氣韻生動）

**氣質關鍵詞**：東方、未來、融合、氣韻、新古典

**適用場景**：文化科技、東亞市場品牌、國際差異化

## 設計方向顧問流程

### 何時觸發

- 使用者需求模糊（「做個好看的」「幫我設計」「不知道要什麼風格」）
- 使用者明確要求「推薦風格」「給幾個方向」
- 專案無品牌 context（無 design system、無參考）

### 何時跳過

- 已有明確風格參考（Figma / 截圖 / 品牌規範）
- 使用者已說清楚方向（「做 McKinsey 風格 deck」）
- 小修改 / 明確的工具呼叫

### 流程（4 Phase）

**Phase 1 · 理解需求**（一次最多 3 題）
- 目標受眾 / 核心訊息 / 情感基調

**Phase 2 · 顧問式重述**（100-200 字）
用自己的話重述需求，以「基於這個理解，我為你準備了 3 個設計方向」結尾。

**Phase 3 · 推薦 3 套設計哲學**

**差異化規則（必守）**：3 個方向**必須來自 3 個不同流派**。

| 位置 | 角色 | 建議流派 |
|---|---|---|
| 方向 A | 安全/專業選擇 | 資訊建築派 或 極簡主義派 |
| 方向 B | 差異化選擇 | 東方哲學派 或 運動詩學派 |
| 方向 C | 大膽/創新選擇 | 實驗先鋒派 或 運動詩學派 |

每個方向必須含：
- 設計師/機構名（如「Kenya Hara 式東方極簡」）
- 50-100 字「為什麼適合你」
- 3-4 條標誌性視覺特徵
- 3-5 個氣質關鍵詞

**Phase 4 · 使用者選擇**
- 選一個深化
- 混合（「A 的配色 + C 的佈局」）
- 微調
- 重來 → 回 Phase 3

選定方向後回到 fe-design pipeline Stage 3 繼續。
